เกมลอยกระทง (พิม & เป๊ปซี่) - เวอร์ชันมือถือแนวตั้ง (Tap-to-Walk)
====================================================================
สิ่งที่ปรับปรุงในเวอร์ชันนี้:
1. ออกแบบ UI สำหรับหน้าจอมือถือแนวตั้งโดยเฉพาะ:
   - นำปุ่มจอยสติ๊กเดินออกทั้งหมด ใช้การ "จิ้มบนพื้น" เพื่อเดินไปยังจุดที่ต้องการอย่างเดียว
   - จัดวางปุ่ม "ไหว้คู่กัน 🙏" คู่กับปุ่มโต้ตอบร้านค้า/ท่าน้ำไว้เหนือแถบกระเป๋า 5 ช่องอย่างลงตัว ไม่ซ้อนทับกัน
   - ปรับแถบช่องเก็บของ 5 ช่องด้านล่างสุดให้เรียงสวยงาม กดสลับไอเทมได้สะดวกด้วยนิ้วโป้งเดียว
2. ปรับมุมกล้องซูมเข้าให้เห็นป้ายชื่อร้านค้าและข้อความพูดคุยบนหัวตัวละครได้ชัดเจนยิ่งขึ้น
3. โฟลเดอร์ sounds/:
   - สามารถนำไฟล์เพลง .mp3 มาวางในโฟลเดอร์ sounds/ ชื่อ song1.mp3, song2.mp3, song3.mp3 ได้เลยครับ ❤️
